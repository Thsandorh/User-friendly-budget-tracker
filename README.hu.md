## 📱 Telepítés

### Webes Verzió (PWA)

1. **Nyisd meg a böngészőben:**
   ```
   https://user-friendly-budget-tracker.vercel.app
   ```

2. **Android Chrome-ban:**
   - Menü (⋮) → **"Hozzáadás a kezdőképernyőhöz"**
   - Kész! Telepítve mint egy app

3. **iPhone Safari-ban:**
   - Megosztás gomb → **"Add to Home Screen"**

### Android Alkalmazás (APK)

1. **Töltsd le a legfrissebb APK-t GitHub-ról:**
   - Menj: `https://github.com/Thsandorh/User-friendly-budget-tracker`
   - Kattints az **Actions** fülre
   - Válaszd ki a legutóbbi **"Build Android APK"** workflow-t
   - Töltsd le az **Artifacts** részből

2. **Telepítés:**
   - Nyisd meg a letöltött APK fájlt
   - Engedélyezd az "Ismeretlen forrásból" telepítést
   - Kattints a **Telepítés** gombra

**Részletes útmutató:** Lásd `ANDROID_BUILD.md`

## 🚀 Gyors Kezdés

### 1. Regisztráció / Bejelentkezés

Első indításkor hozz létre egy fiókot:
- **Email cím**
- **Jelszó**
- **Név**

### 2. Első Tranzakció Hozzáadása

1. Kattints a **"Tranzakciók"** menüpontra
2. Kattints a **"+ Új tranzakció"** gombra
3. Töltsd ki az adatokat:
   - Összeg
   - Leírás
   - Típus (bevétel/kiadás)
   - Kategória
   - Dátum
4. **Mentés**

### 3. Költségvetés Létrehozása

1. Menj a **"Költségvetések"** menübe
2. Kattints a **"+ Új költségvetés"** gombra
3. Add meg:
   - Név (pl. "Havi költségvetés")
   - Összeg (pl. 200,000 Ft)
   - Időszak (havi/heti/éves)
   - Kezdő dátum
4. **Mentés**

### 4. Napi Limit Beállítása ⭐ ÚJ!

1. A **Dashboard**-on látod a "Napi limit" kártyát
2. Kattints a **"Limit beállítása"** gombra
3. Add meg a napi költési limitet (pl. 5,000 Ft)
4. **Mentés**

Ettől kezdve:
- ✅ **Zöld pipa** jelenik meg ha nem lépted túl a limitet
- **Hátralévő összeg** látható
- ❌ **Piros figyelmeztetés** ha túllépted
- **Pontosan látod mennyivel** lépted túl

### 5. Kategóriák Testreszabása

1. Menj a **"Kategóriák"** menübe
2. Kattints a **"+ Új kategória"** gombra
3. Állítsd be:
   - Név
   - Ikon (emoji)
   - Szín
   - Típus (bevétel/kiadás)
4. **Mentés**

## ❓ Gyakori Kérdések (GYIK)

### Hogyan működik az offline mód?
Az alkalmazás PWA (Progressive Web App) technológiát használ. Az adatok helyileg tárolódnak a böngésződben, így internet nélkül is működik. Amikor újra online vagy, automatikusan szinkronizál.

### Biztonságosak az adataim?
Igen! Jelszavad titkosítva van (bcrypt), az adatkapcsolat HTTPS-en keresztül történik, és az adatok biztonságos PostgreSQL adatbázisban vannak tárolva.

### Használhatom több eszközön?
Igen! Jelentkezz be ugyanazzal a fiókkal több eszközről is, és az adatok automatikusan szinkronizálódnak.

### Mennyibe kerül?
Az alkalmazás teljesen **INGYENES**! Nincs rejtett költség, előfizetés vagy in-app vásárlás.

### Hogyan működik a nyugta szkennelés?
Készíts fotót a nyugtáról a telefonoddal. Az OCR (Optical Character Recognition) technológia felismeri a szöveget és automatikusan kitölti a mezőket.

### Mi van ha törlöm az appot?
Az adatok a felhőben tárolódnak, így ha újra telepíted és bejelentkezel, minden megmarad.

### Exportálhatom az adataimat?
Igen! A riportokat PDF formátumban exportálhatod.
